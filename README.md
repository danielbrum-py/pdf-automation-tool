# 📄 PDF Automation Tool (Batch PDF Merger)

---

## 📌 About the Project

This project aims to automate the process of merging multiple PDF files into a single document in a fast and efficient way.

The application was created to solve a real personal need: organizing and combining course certificates into one unified PDF, eliminating the manual process of opening and merging files one by one.

The tool processes multiple PDF files from a selected folder and generates a single consolidated output file, improving productivity for academic, professional, and administrative use cases.

---

## 🎯 Project Objectives

* Automate the merging of multiple PDF files
* Simplify document organization and management
* Practice file handling and automation with Python
* Build a practical utility tool for real-world usage

---

## 🛠️ Technologies Used

* Python 🐍
* pypdf / PyPDF2

---

## 🧱 Project Stages

### 1. 📂 File Collection

* Reading PDF files from a directory
* Filtering valid PDF documents
* Organizing file order for merging

### 2. 🔄 PDF Processing

* Opening and reading PDF files
* Extracting pages from each document
* Preparing files for merging

### 3. 📎 Merging Logic

* Combining multiple PDFs into a single file
* Maintaining correct page order
* Generating final output document

### 4. 💾 Output Generation

* Saving the merged PDF file
* Defining output directory
* Handling file overwriting safely
